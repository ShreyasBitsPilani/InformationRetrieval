# Information Retrieval System — Assignment 2

An end-to-end Information Retrieval (IR) system implemented in Python. The project covers dataset construction, text preprocessing, keyword extraction, document profiling, inverted indexing, TF-IDF retrieval, PageRank, hybrid ranking, content-based recommendation, retrieval evaluation, analytics, and an interactive Streamlit application.

# 12. Hybrid Ranking

The project combines textual relevance from TF-IDF with document importance from PageRank.

The hybrid score used by the application is:

```text
Hybrid Score =
0.70 × TF-IDF Score
+
0.30 × Normalized PageRank
```

Therefore, hybrid ranking considers both:

1. Relevance of the document to the query.
2. Importance of the document in the document graph.

# 15. Evaluation Metrics

The evaluation module calculates standard Information Retrieval metrics.

## Precision

Precision measures the proportion of retrieved documents that are relevant.

```text
Precision =
Relevant Retrieved Documents
----------------------------
Total Retrieved Documents
```

## Recall

Recall measures the proportion of relevant documents that were retrieved.

```text
Recall =
Relevant Retrieved Documents
----------------------------
Total Relevant Documents
```

## F1 Score

F1 Score combines Precision and Recall.

```text
F1 =
2 × Precision × Recall
----------------------
Precision + Recall
```

## Precision@K

Measures precision among the top K retrieved documents.

## Recall@K

Measures recall among the top K retrieved documents.

## MAP

Mean Average Precision evaluates the ranking quality across multiple queries.

## MRR

Mean Reciprocal Rank measures the position of the first relevant result.

## NDCG

Normalized Discounted Cumulative Gain evaluates ranking quality while considering the position of relevant documents.

# 31. Conclusion

The project implements an end-to-end Information Retrieval system that integrates document processing, indexing, retrieval, link analysis, ranking, recommendation, evaluation, and visualization.

The main retrieval approach uses TF-IDF to measure textual relevance. PageRank is then used as a document-authority signal, and the two signals are combined through hybrid ranking.

The recommendation component uses document similarity to provide content-based recommendations.

The evaluation component compares TF-IDF and Hybrid ranking using standard Information Retrieval metrics.

Finally, the complete system is exposed through an interactive Streamlit application that allows users to search documents, explore document profiles, view PageRank information, generate recommendations, inspect analytics, and compare retrieval performance.
